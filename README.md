# Smart-Fire-Detection-System

基於 Raspberry Pi 3 Model B 的多感測器智慧火災偵測與安全系統（規劃中）。

> **目前狀態：規劃階段。** 這個倉庫目前只有本 README，尚未提交程式碼、感測器接線圖、相依套件清單或測試結果。以下標示 **Planned** 的內容是開發方向，不代表已實作或驗證。本專案目前不可作為實際的消防警報設備使用。

## 專案目標

- **Planned：** 使用多種感測器觀察與火災相關的環境變化，探索比單一訊號更可靠的判斷方式。
- **Planned：** 在 Raspberry Pi 3 Model B 上整合資料讀取、判斷與本地警報，並記錄事件以便分析。
- **Planned：** 將設計、接線、測試方法及程式碼逐步公開，作為嵌入式系統學習與作品集專案。

## 系統架構（Planned）

```text
環境感測器（型號待定）
        │
        ▼
Raspberry Pi 3 Model B
        ├── 資料讀取與基本檢查
        ├── 多感測器判斷邏輯
        ├── 本地警報（輸出裝置待定）
        └── 事件紀錄／遠端通知（後續評估）
```

此圖是預定的資料流程，尚非已完成的系統架構。感測器介面、取樣週期、判斷門檻與通知方式都尚未決定。

## 預定硬體

| 項目 | 狀態 | 說明 |
| --- | --- | --- |
| Raspberry Pi 3 Model B | 已持有；尚未在此倉庫展示整合成果 | 預定作為主要控制板 |
| 溫度感測器 | Planned | 型號與連接方式待選定 |
| 煙霧／氣體感測器 | Planned | 型號、適用性、供電及訊號介面待評估 |
| 火焰感測器 | Planned，可選 | 是否採用及型號待評估 |
| 蜂鳴器或其他本地警報裝置 | Planned | 型號與驅動方式待定 |
| 電源、接線及必要的介面電路 | Planned | 依最終元件規格設計；不可直接假設感測器輸出與 Pi GPIO 相容 |

預定元件不等於採購清單。選型時需要核對 Raspberry Pi GPIO 的 **3.3 V 電平限制**；類比輸出感測器若要接入 Pi，可能需要 ADC 或其他介面電路。

## 功能模組（Planned）

1. **感測資料擷取：** 讀取選定感測器，處理讀值失敗或異常資料。
2. **狀態判斷：** 根據多感測器資料與可調參數判斷正常、疑似異常及警報狀態；規則與門檻待實測。
3. **本地警報：** 觸發選定的提示裝置，並設計復位方式。
4. **事件紀錄：** 保存時間、讀值及狀態變化，供測試與分析。
5. **遠端通知：** 後續視需求與網路條件評估，尚未選定平台或通訊方式。

上述模組皆尚未實作。實際功能與範圍會隨硬體選型及測試結果調整。
